# Domain Documentation

This repository uses a single-context domain layout.

- The root `CONTEXT.md`, when present, describes the repository domain.
- Architecture decisions belong in `docs/adr/`.
- Before changing domain behavior, read the relevant context and ADR files.
- When adding a new domain concept or making a significant architectural decision, update the relevant context or add an ADR.
- Keep domain terminology consistent with the existing workshop documentation.
