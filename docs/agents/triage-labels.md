# Triage Labels

Use these canonical triage labels for GitHub Issues:

- `needs-triage`: The issue has not been assessed yet.
- `needs-info`: More information is required before implementation.
- `ready-for-agent`: The issue is sufficiently specified for an agent to implement.
- `ready-for-human`: The issue needs human review or a human decision.
- `wontfix`: The issue will not be implemented.
